## 학습 기록

### 2026-09-06: japantravelsite 모바일 반응형 레이아웃(375px) 실측 최적화
- **원인 분석**:
  - `.guide-page .article-layout`(특이도 0,2,0)이 미디어쿼리 내 `.article-layout`(0,1,0) 리셋을 덮어써 375px에서 본문 칼럼이 92px로 찌그러지는 현상 발생.
  - 그리드 컨테이너의 암묵적 `1fr`(auto 최소값)으로 인해 본문이 610px로 부풀어 가로 오버플로 250px 발생.
- **해결 패턴**:
  1. **칼럼 보강**: 레이아웃 컨테이너 `1fr` -> `minmax(0, 1fr)`로 축소 방지 (가이드 본문 92px -> 347px 복원).
  2. **OTA 버튼 겹침 방지**: `min-width: 0` 적용 및 라벨 말줄임(ellipsis) 보강, `repeat(auto-fit, minmax(min(200px, 100%), 1fr))`로 뷰포트가 아닌 카드 폭 기준 2열<->1열 자동 전환.
  3. **버튼 폭 확보**: 호텔스컴바인 등 긴 라벨 잘림 방지를 위해 열 너비 250px -> 268px 확장.
  4. **검증 결과**: 9개 라우트 x 9개 뷰포트(320~1440px) 전 구간 가로 오버플로 0px, 라벨 잘림 0건 달성.
- **적용 커밋**: `japantravelsite` (`98ff69c`)
