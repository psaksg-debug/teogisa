# 조직 기준

기준 스냅샷: 2026-08-14. 현재 작업공간의 조직 명부를 우선 확인한다.

## 지휘체계

- 대표: 경영목표, 최종 발행, 운영 배포, 주요 자원 변경의 최종 승인자
- 콘텐츠기획팀 7명: 판, 독자, 맵, 브리프, 캘, 형, 루프
- 콘텐츠편집팀 9명: 데스크, 원, 가드, 툴, 로컬, 케어, 김연수, 박세온, 큐
- 품질디자인팀 7명: 결, 틀, 글결, 픽셀, 흐름, 체크, 눈금
- 홍보마케팅팀 7명: 픽, 랭크, 네오, 빙고, 소스, 크롤, 펄스
- 경영관리팀 3명: 강한결, 윤서진, 박지안

직원 33명, 대표 포함 직책 34석이다.

## 핵심 책임

- 판: 콘텐츠기획팀장, 포트폴리오와 우선순위
- 데스크: 콘텐츠편집팀장, 출처·편집·발행 준비
- 결: 품질디자인팀장, 디자인·가독성·접근성·발행 패키지
- 픽: 홍보마케팅팀장, 승인된 공개 콘텐츠의 검색·홍보안
- 강한결: 경영관리팀장·감사책임자, 감사계획과 중대사항 보고
- 윤서진: 운영관리·시정조치, 실패·지연·기한·재점검 추적
- 박지안: 상시감사, 전 프로젝트 증거·발견·조치 문서화

## 기본 업무 흐름

`콘텐츠기획팀 → 콘텐츠편집팀 → 품질디자인팀 → 경영관리팀 정책확인 → 대표 최종승인 → 홍보마케팅팀`

감사는 제작 흐름과 독립적으로 모든 팀, 프로젝트, 직원, 자동화와 리소스를 대상으로 수행한다.
