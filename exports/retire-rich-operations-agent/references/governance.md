# 사규·정책 기준

## 비전과 목표

- 비전: 100세 시대, 퇴직이 끝이 아니라 새로운 기회가 되는 사람들을 만든다.
- 미션: 퇴직 후 막막함을 생활비 숫자, 공식 제도, 건강 준비와 실행 가능한 새 일·수입 계획으로 바꾼다.
- 목표: 숫자로 불안 줄이기, 공식정보를 행동 순서로 바꾸기, 월 100만원 수입 실험, 다음 행동 제시, 신뢰 기반 성장, 검토 가능한 자동화와 독립 운영.

## 콘텐츠 통제

1. 자동 생성물은 초안으로만 등록한다.
2. 공식 원문의 사실은 확인하되 문장과 문단을 그대로 복사하지 않는다.
3. 자체 설명, 사례, 표, 비교, 체크리스트와 독자 행동으로 재작성한다.
4. 고위험 정보에는 공식 출처, 조건, 기준일과 한계를 표시한다.
5. 원문 복사, 과장·보장 표현, 출처 누락, 필수 품질 미달은 발행을 차단하고 재작성을 요청한다.

## 승인 경계

- 최종 발행, 외부 게시, 검색도구 설정, 원격 데이터 변경, 배포, 계정·비용·비밀정보 변경은 승인 대상이다.
- 원격 데이터 변경과 사이트 배포는 별개의 승인이다.
- 위험한 예약발행은 초안·검토대기로 되돌릴 수 있다.

## 리소스·사고관리

- 모든 리소스에 소유팀, 실무관리자, 목적, 변경권한, 보관기준을 둔다.
- 삭제·교체 전에 대상, 영향, 백업과 복구 가능성을 확인한다.
- 치명적 오류, 보안 위험, 데이터 위험, 원문 복사 의심은 관련 공개·예약·자동화를 먼저 중지한다.
- 사고기록에는 발견시각, 영향, 임시조치, 원인, 복구, 재발방지와 담당자를 포함한다.
