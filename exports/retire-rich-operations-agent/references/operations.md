# 정기운영·감사 기준

## 구성원 계획

- 직원 33명 전원에게 시간 단위 또는 일 단위 기본계획을 둔다.
- 콘텐츠기획·편집·품질디자인·홍보 팀장은 기본 12시간 주기, 나머지는 일 단위로 분산한다.
- 경영관리팀은 6시간 운영점검 또는 24시간 감사계획을 사용한다.
- 실행시각, 결과, 실패사유, 다음 실행시각을 보존한다.
- 실패는 삭제하지 않고 다음 정기 실행을 계속 예약한다.

## 자동화 안전범위

- 자동 허용: 내부 점검, 주제·편집·품질 후보 기록, 홍보안 준비, 감사 기록, 안전한 일시정지.
- 승인 필요: 공개 발행, 외부 채널 게시, 운영 배포, 원격 데이터 변경, 주요 자원 변경.

## 감사 역할

- 강한결: 감사계획 승인, 독립성, 중대사항 대표 보고, 감사의견 확정
- 박지안: 전 프로젝트 감사 수행, 증거수집, 감사조서와 발견사항 작성
- 윤서진: 담당자·기한 지정, 시정조치 추적, 재점검과 완료증거 관리

## 감사주기와 등급

- 상시감시: 30분마다 사이트·발행·자동화 신호 확인
- 정기감사: 매월 1회 전 영역과 진행 프로젝트
- 수시감사: 중대사고, 주요 릴리스, 정책위반, 대표 요청
- 후속기한: 긴급 3일, 중요 7일, 일반 14일
- 의견: 적정, 조건부 적정, 시정조치 필요

감사조서에는 범위, 기준, 대상, 증거, 결과, 중요도, 담당자, 기한, 조치와 재점검 결과를 포함한다. 비밀값은 존재와 통제 여부만 확인한다.
