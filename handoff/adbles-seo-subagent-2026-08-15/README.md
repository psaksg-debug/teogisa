# ADBLES SEO 서브에이전트 인수인계 패키지

작성 기준일: 2026-08-15 KST

이 패키지는 현재 대화의 요구사항을 다른 Codex 작업이나 서브에이전트가 안전하게 이어받도록 정리한 휴대용 문서 묶음입니다. 계정 비밀번호, API 토큰, 배포 자격 증명은 포함하지 않았습니다.

## 사용 순서

1. ZIP을 대상 환경으로 옮겨 압축을 풉니다.
2. `SUBAGENT_PROMPT.md` 전체를 새 에이전트의 첫 지시로 전달합니다.
3. `PROJECT_STATE.md`로 작성 당시 상태와 현재 코드의 차이를 확인합니다.
4. `CONVERSATION_SUMMARY.md`에서 사용자가 정한 방향과 과거 장애를 확인합니다.
5. 반복 자동화를 만들 때만 `SEO_AUTOMATION_PROMPT.md`를 사용합니다. 기존 자동화가 있으면 새로 만들지 말고 갱신합니다.

## 파일 구성

- `SUBAGENT_PROMPT.md`: 바로 붙여 넣어 실행할 수 있는 주 지시문
- `PROJECT_STATE.md`: 저장소·공개 사이트·조직의 현재 스냅샷
- `CONVERSATION_SUMMARY.md`: 대화에서 확정된 요구와 사건 요약
- `SEO_AUTOMATION_PROMPT.md`: 오전 9시·오후 6시 반복 점검용 프롬프트
- `RUNBOOK.md`: 명령, 판정 기준, 보고 형식

## 중요한 원칙

- 문서의 스냅샷보다 현재 코드와 공개 사이트를 우선하며, 둘을 다시 확인합니다.
- 로컬 구현 완료, 원격 반영, Production 배포, 사용자 확인을 서로 구분합니다.
- 배포·DNS·Cloudflare·원격 DB·검색도구 설정·외부 게시·광고 집행은 새 승인을 받기 전 실행하지 않습니다.
- AI 콘텐츠는 `AI 초안 → 사람 검토 → 예약 발행` 절차를 유지합니다.
